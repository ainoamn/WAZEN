## 1. منع تكرار الاسم والهاتف والبريد

داخل **نفس الجمعية** لا يُقبل عضو نشط بنفس الاسم أو الهاتف (بعد تطبيع عمان/واتساب) أو البريد.

عند التكرار تظهر ملاحظة: **هذا المستخدم موجود. للمتابعة حرّر بياناته.** مع زر **تحرير البيانات** يفتح بطاقة العضو الحالي.

| ملف | الدور |
|-----|--------|
| `lib/member-contact-unique.ts` | كشف التكرار + الرسائل + `conflictMemberId` |
| `app/api/dashboard/route.ts` | `addMember` / `updateMemberContact` |
| `app/api/platform/route.ts` | `inviteMember` |
| `lib/v1-members.ts` · `lib/v1-member-patch.ts` | API v1 |
| `app/wazen-dashboard.tsx` | نافذة الإضافة + زر التحرير |

## 2. أداة دمج المكررات (بدون المساس بالحسابات الأخرى)

في صفحة الأعضاء يظهر زر **دمج المكرر (العدد)** إن وُجدت مجموعات تكرار.

- الدمج **داخل الجمعية الواحدة فقط** — نفس الشخص في جمعية أخرى يبقى عضوية مستقلة.
- يُجمع المدفوع؛ **لا يُضاعف** الاشتراك المستحق.
- حصص المصروف الخاصة بالمكرر تُنقل إليه فقط — أرصدة الأعضاء الآخرين لا تُعاد تقسيمها تلقائياً.
- حسابان مرتبطان بتسجيل دخول مختلف (`user_id` مختلف) **لا يُدمجان**.

| ملف | الدور |
|-----|--------|
| `lib/member-duplicates.ts` | التجميع، اختيار السجل الأساس، الدمج الآمن |
| `components/members/duplicate-merge-panel.tsx` | الواجهة والعدد |
| `POST /api/dashboard` · `mergeMemberDuplicates` | دمج مجموعة أو كل الآمن (`mergeAll: true`) |

## 3. جهات الاتصال عند الدعوة

في نافذة **إضافة مساهم**:

- **من الهاتف:** Contact Picker بعد منح الصلاحية (Chrome/Android + HTTPS).
- **رفع ملف / بريد:** vCard أو CSV من الهاتف أو Gmail/Outlook.
- **تنزيل** الجهات المحفوظة vCard / CSV.

| ملف | الدور |
|-----|--------|
| `lib/contact-file.ts` | تحليل وتصدير vCard/CSV |
| `components/members/contact-source-bar.tsx` | أزرار الهاتف/الملف/التنزيل |
| `POST /api/dashboard` · `importSavedContacts` | حفظ في `saved_contacts` |

## تحقق بعد النشر

1. `/dashboard?view=groups` → إن وُجد تكرار يظهر زر الدمج بالعدد.
2. إضافة مساهم بنفس رقم موجود → ملاحظة + تحرير البيانات (لا سجل جديد).
3. دعوة → من الهاتف أو رفع `.vcf` / `.csv` يملأ النموذج.
