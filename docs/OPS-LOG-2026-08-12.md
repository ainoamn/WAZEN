## الخطوة التالية للمالك

1. اختر كلمة مرور جديدة ≥ 12 حرفاً (ولا ترسلها في المحادثة إن أمكن).
2. أكّد: البيانات الحالية كلها تجريبية.
3. وفّر وصول Turso (أو أنشئ قاعدة `wazen-production-v1`) واربط Vercel:
   - `WAZEN_DEMO_MODE=0`
   - `WAZEN_USE_NODE_SQLITE=0`
   - `WAZEN_TRUST_OAI_HEADERS=0`
   - `WAZEN_ADMIN_EMAILS=admin@wazen.pro` (مؤقتاً فقط)
4. بعد نشر `main` الحالي:
   ```bash
   npm run db:migrate
   npm run admin:bootstrap -- --email admin@wazen.pro --name "Wazen Admin" --origin https://YOUR_DOMAIN
   ```
5. افتح رابط التهيئة مرة واحدة، عيّن كلمة المرور (≥12)، ثم فعّل TOTP فوراً من `/account/security`.
6. أنشئ مديراً احتياطياً، ثم احذف `WAZEN_ADMIN_EMAILS` من Vercel وأعد النشر.

**تحذير أمني:** لا تحفظ كلمة المرور في Git أو `.env` دائم أو وثائق عامة. اعتبر كلمة المرور المرسلة في الدردشة معرّضة وافرض تغييراً فورياً بعد التهيئة.
