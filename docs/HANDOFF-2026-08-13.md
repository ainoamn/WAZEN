## أين وقفنا الآن

### مكتمل في هذه الجولة

1. **إزالة الإحصاءات الوهمية من لوحة المستخدم**  
   - ملاحظة وازن / دونات 72% / نسب السكن والطعام… كانت ثابتة في الواجهة → أصبحت حالة فارغة حتى توجد مصروفات منزل حقيقية.  
   - نسب KPI الوهمية (`+6.4%`, `+12%`, `-8%`) أُزيلت.  
   - الالتزامات القادمة لم تعد تعرض 2000/20000 ثابتة + «3 من 4 مكتملة».  
   - شارة الأعضاء `5` الثابتة في الشريط الجانبي أُزيلت.  
   - تاريخ الشريحة أصبح تاريخ اليوم بدل `2026-08-11`.  
   - تقارير التدفق لا ترسم أعمدة وهمية عند عدم وجود بيانات.

2. **تسريع التنقل وإدخال البيانات (جزئي)**  
   - `ensureUser` لم يعد يعيد كتابة صف المستخدم في كل طلب؛ يحدّث `last_seen` فقط للمستخدمين الحاليين.  
   - `scopedAdminData` لصفحات payments/reports يجلب بيانات محدودة بدل كل جداول الإدارة.  
   - كاش عميل لصفحات الإدارة + prefetch (من الجولة السابقة).  
   - إيقاف reseeding الباقات/البوابات في كل طلب (من الجولة السابقة).

3. **نظام الباقات وبوابات الدفع** (مكتمل سابقاً وما زال في `main`)  
   - `/admin/gateways`, `/admin/plans`, تحكم اشتراك المستخدم، entitlements.

## تشغيل الجهاز الآخر بدون تعارض

```bash
git pull --ff-only origin main
npm ci
# انسخ .env.local محلياً — لا ترفعه إلى Git
npm run dev
```

1. اعمل على فرع أو ادفع إلى `main` فقط بعد `pull --ff-only`.  
2. لا ترفع `.env` أو كلمات مرور Neon.  
3. إن ظهر تعارض: حلّه commit جديد — بدون `--force` على `main`.  
4. النشر عند الحاجة: `npx vercel --prod --yes`.

## تحقق سريع

1. حساب بلا محافظ → لوحة المستخدم تظهر حالات فارغة، بلا دونات 72% أو نسب وهمية.
