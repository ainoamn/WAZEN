# Handoff — متابعة العمل من جهاز آخر

**تاريخ التحديث:** 13 أغسطس 2026 (مساءً — جولة الإدارة/التفعيل)  
**الفرع:** `main`  
**الإنتاج:** https://wazen-roan.vercel.app  
**المستودع:** https://github.com/ainoamn/WAZEN  

> قبل أي عمل على الجهاز الآخر: `git pull --ff-only origin main` ثم لا تستخدم force push على `main`.

---

## أين وقفنا الآن

### مكتمل في هذه الجولة

1. **إصلاح تحكم الاشتراك من الإدارة**  
   - منح اشتراك جديد إن لم يوجد (`INSERT` وليس فقط `UPDATE`).  
   - أخطاء الحفظ كانت تُخفى في الواجهة → تظهر الآن برسالة واضحة.  
   - حقول الاشتراك أصبحت معنونة، والباقات تُحمَّل مع تفاصيل المستخدم.  
   - قبول تاريخ نهاية الفترة بصيغة `YYYY-MM-DD` أو ISO.

2. **تفعيل الحساب يدوياً**  
   - زر «تفعيل الحساب يدوياً» في `/admin/users/[id]` عندما `email_verified_at` فارغ.  
   - Action: `adminVerifyEmail` (يحدّث `auth_credentials` ويلغي رموز التحقق المعلّقة + audit).

3. **تعديل بيانات الحساب**  
   - الاسم الظاهر + حالة الحساب (`active` / `suspended` / `closed`).  
   - Action: `adminUpdateUser`.

4. **مؤشر التنقل (من الجولة السابقة إن وُجد في نفس الدفع)**  
   - شعار الموقع الرسمي + قلب يمتلئ أثناء التنقل/التحميل.

5. **إزالة الإحصاءات الوهمية + تسريع جزئي** (سابقاً في `main`).

## تشغيل الجهاز الآخر بدون تعارض

```bash
git pull --ff-only origin main
npm ci
# انسخ .env.local محلياً — لا ترفعه إلى Git
npm run dev
```

1. اعمل على فرع أو ادفع إلى `main` فقط بعد `pull --ff-only`.  
2. لا ترفع `.env` أو كلمات مرور Neon.  
3. إن ظهر تعارض: حلّه commit جديد — بدون `--force` على `main`.  
4. النشر عند الحاجة: `npx vercel --prod --yes`.

---

## تحقق سريع

1. `/admin/users/:id` → غيّر الباقة/الحالة → «حفظ الاشتراك» يظهر نجاحاً وتتحدث الـ KPIs.  
2. مستخدم بلا اشتراك → اختر باقة → يُنشأ اشتراك.  
3. مستخدم غير مفعّل البريد → «تفعيل الحساب يدوياً» ثم يستطيع تسجيل الدخول.  
4. غيّر الاسم/حالة الحساب واحفظ.  
5. التنقل بين الصفحات يظهر شعار وازن + قلب يمتلئ.  
6. `npm run typecheck`.
