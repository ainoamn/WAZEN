## مكتمل في هذه الجولة

### 1) قواعد المحاسبة (دخل العضو + المصروف)
- دفع من عضو يخصم من **كامل المطالبات المتراكمة** (`due − paid`)، وليس قسط شهر فقط.
- إن لم يبقَ عليه شيء / زاد المبلغ → يُسجَّل **مقدّماً (له)**.
- المصروف الجماعي: اختيار **دُفع من** صندوق المجموعة أو حساب عضو.
- جدول الأعضاء يعرض **عليه / له** (مستحقات + مقدّم + فائض + تسويات).

### 2) التقارير المنزّلة بشعار وازن
- قسم التقارير: أنواع متعددة (جمعية، عميل، مصاريف، دخل، عام، إحصائيات، انضباط، التزام، تأخير، تقييم، اشتراكات، تجديد، متأخرات، تخفيضات، فوائد، التزامات).
- كل تنزيل/طباعة: **شعار الموقع → اسم الجمعية/المحفظة → البيانات**.
- ملفات: `lib/reports.ts`, `components/reports/ReportsPanel.tsx`.

### 3) بطء التنقل / الإحساس بالتجمّد
- أُزيلت شاشة التحميل الكاملة عند كل رابط (كانت تغطي الصفحة بشعار + blur).
- بدلها **شريط تقدّم رفيع أعلى الصفحة** يظهر فقط إذا تجاوز الانتقال ~120ms.
- تخفيف تحميل اللوحة:
  - لا إعادة احتساب سجلات الأعضاء (`reconcile`) في كل `GET`.
  - لا كتابة `last_seen` في كل طلب لوحة للمستخدم الموجود.
  - إعادة الاحتساب تبقى بعد عمليات الكتابة (إضافة/تعديل/إلغاء…).

### 4) اختبارات
- `tests/finance.test.mjs` — تقسيم المستحق ثم المقدّم.
- `tests/reports.test.mjs` — كتالوج التقارير + وجود الشعار والاسم في HTML.
- إصلاح اختبار الأمان ليتوافق مع Neon (`DATABASE_URL`) وليس Turso فقط.

## تحقق سريع

1. سجّل دخلاً/مساهمة لعضو عليه 240 → يخصم من 240؛ الزيادة مقدّم.  
2. مصروف جماعي من صندوق أو من عضو → يظهر له/عليه.  
3. التقارير → اختر نوعاً → تنزيل أو طباعة PDF: يظهر الشعار واسم المحفظة.  
4. انتقل بين `/dashboard` و `/documents` و `/admin`: بدون شاشة كاملة؛ شريط أعلى فقط عند البطء.  
5. `npm run typecheck && npm run test:backend`
