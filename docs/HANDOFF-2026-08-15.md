## 1) فتح المشروع على الجهاز الثاني

المتطلبات: **Node.js 22.x** (مثبّت في `package.json`. Vercel يستخدم 22 وليس 24).

```powershell
git clone https://github.com/ainoamn/WAZEN.git
cd WAZEN
git checkout main
git pull --ff-only origin main
npm install
copy .env.example .env.local
# املأ الأسرار من Vercel / Neon — لا تضعها في Git
npm run setup:local
npm run dev
```

الجداول الجديدة (`space_links`, `space_bank_links`) تُنشأ عند أول طلب عبر `ensureSchema` (`SCHEMA_VERSION = 2` في `db/runtime.ts`). ملف الهجرة: `drizzle/0006_space_links.sql`.

اختبارات وبناء:

```powershell
npm run test:backend
npm run build
```

النشر: الدفع إلى `main` يشغّل Vercel تلقائياً.

## 3) ما اكتمل في 15 أغسطس 2026

### طي وفتح أقسام المحفظة

- مكوّن: `components/ui/collapsible-panel.tsx` (`CollapsiblePanel`, `FoldWrap`).
- الحالة تُحفظ في `localStorage` تحت المفتاح `wazen-fold`.
- يغطي: رأس المحفظة، الملخص، التنبؤ، الحسابات، حساب الأشهر (وكل شهر)، الدخل الآخر، الأقساط، صندوق المنزل، المصروفات، الأعضاء، العمليات، الفترات، نظرة عامة (أحدث العمليات / الالتزامات).
- أنماط: `app/globals.css` (`.fold-wrap`, `.panel-fold`, `.is-collapsed`).

### ربط المحافظ وفصل الأموال (المحفظة الشخصية)

الغرض: من يدير محفظته + محفظة الأطفال + جمعيات على نفس الحساب البنكي يرى **أمواله** منفصلة عن **أموال كل محفظة**.

| إجراء API | الوظيفة |
|-----------|---------|
| `linkWallet` | ربط محفظة/جمعية بالمحفظة الشخصية |
| `unlinkWallet` | فصل الربط (يحذف أيضاً ربط البنك) |
| `setWalletBankLink` | تعيين أو إزالة الحساب البنكي الذي تُحفظ عليه أموال المحفظة المرتبطة |
| `transferLinkedFunds` | تحويل `to_linked` (من أموالك إلى المحفظة) أو `to_hub` (العكس) |

الجداول:

- `space_links`: `hub_space_id` (شخصية) + `linked_space_id`
- `space_bank_links`: المحفظة المرتبطة + `account_id` من `personal_accounts`

العرض على بطاقة الحساب: **أموالك** = رصيد الحساب الشخصي؛ **كل محفظة مربوطة** = `balance_minor` لتلك المحفظة؛ **المجموع** = ما يُفترض أنه في البنك.

منطق الفصل: `lib/wallet-links.ts` (`bankCustodySplit`).  
الواجهة: قسم «ربط المحافظ» في `components/personal/personal-wallet.tsx`.

سلوك التحويل: مصروف على المصدر + دخل على الوجهة، مع `account_id` على حركة الحساب الشخصي. لا يُسمح بتحويل أكبر من رصيدك (أو رصيد المحفظة المرتبطة عند الاتجاه العكسي).

### سلوك سابق لم يُعكس (ما زال سارياً)

- إلغاء عملية من أحدث العمليات يبقيها ملغاة في السجل ويعيد بند الشهر إلى معلّق (اعتماد / تأجيل / تجاهل).
- إجمالي الشهر يحسب الدخل/الصرف **المرحّل فقط**؛ المعلّق يظهر ملاحظة ولا يُخصم من الصرف حتى الاعتماد.
- حقل «المدفوع» قابل للتعديل على بنود الشهر.
